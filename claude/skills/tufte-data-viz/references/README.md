# References — Conceptual Foundations

The `rules/` directory has the *what* and *how* (per-library config). This `references/` directory has the *why* — the principles the rules derive from. Read these when a rule feels wrong for the situation and you need to think from first principles, not when generating a chart.

| File | Covers | When to read |
|------|--------|--------------|
| `tufte-principles.md` | Data-ink, chartjunk, small multiples, range-frame, sparklines, lie factor | Choosing what to remove vs. preserve; justifying deviations |
| `bertin-variables.md` | Visual variables and what each can encode (selective, associative, ordered, quantitative) | Choosing the encoding (which variable for which data type) |
| `wurman-latch.md` | Location, Alphabet, Time, Category, Hierarchy | Ordering items in tables, legends, small-multiple grids |
| `titles-as-claims.md` | Writing titles that assert findings (skill rule 20) | Drafting chart titles, subtitles, annotations |
