# Second Opinions

When a second opinion is worth its cost — the same approach has failed twice, a high-ambiguity design call, corroborating a high-stakes conclusion — get it from a **different model family**, not another call to the one already stuck. Three channels: a Fable subagent (Agent tool, `model: "fable"`) for judgment, architecture, and research taste; `codex-companion` (via the Monitor tool: `adversarial-review` for diffs, `plan-review` for plans, `task` for investigation) for concrete code-level critique; the `openrouter` CLI (`custom_bins/openrouter`) for the OpenRouter families — `openrouter ask <alias> "<prompt>"` for one model, `openrouter fusion "<prompt>"` for a multi-family panel with judge synthesis (aliases and panel in `config/openrouter-models.yaml`; needs `OPENROUTER_API_KEY` via `setup-envrc` or `with-secrets`).

**Never reach OpenRouter families through subagents.** Agent-frontmatter `model:` names resolve against api.anthropic.com only, so a non-Anthropic name either hard-fails ("issue with the selected model") or answers from Claude wearing another family's label — the old `kimi-k3`/`glm-5.3`/`qwen3.8-max`/`muse-spark-1.2` agents were deleted for exactly this on 2026-08-25. The model-router gateway that once made such names resolve is unwired because it hard-disables Remote Control; the CLI is the sanctioned route.

Unlike `advisor`, none of these has memory of the conversation — brief them fresh with full self-contained context.
