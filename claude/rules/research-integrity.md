# Research Integrity

**Reviewer test:** before any methodological shortcut, ask whether a reviewer seeing it would find it suspect. If maybe — find the principled approach. No "it's just a quick analysis" exception.

**No circular reasoning:** never use an outcome to determine the label, then measure that outcome. General test: if removing the step would change the reported result, and the step depends on the result, it's circular.

**Separation of concerns:** labelling comes from experimental design, never from outcomes → scoring is computed from raw outputs, blind to labels → analysis joins the two. Any stage peeking at another's output is a leak.

**Report what happened:** all conditions, including ones that didn't work; never quietly drop failed conditions, outliers, or null results; investigate surprises rather than explaining them away; state effect sizes with uncertainty (CI/SE), not just significance.

**Every estimate carries an interval, and the interval names what it covers.** No bare point estimate — proportions get Wilson (never normal-approximation, which misbehaves at 0 and 1), differences on paired data get a paired interval or an exact test, anything without a closed form gets a bootstrap. Small denominators are stated as counts next to the percentage (0/7, not "0%"), because the Wilson upper bound on 0/7 is 35.4% and the percentage alone hides that. **The failure mode is not a missing interval but a confidently narrow one**: a CI that covers only sampling over items, while the measurement instrument itself is stochastic across repeats, looks rigorous and understates the truth. So say which sources of variation the interval includes and which it omits — and when a known source is omitted, say so where the number is displayed, not only in the write-up. Overlapping intervals are never a substitute for a paired test on paired data.

**Every number ships with its null and its ceiling.** A rate is uninterpretable alone, because the trivial baseline that produces it is usually most of it. State the **null** — what the number would be with no signal at all — next to the number itself, never in a footnote: for agreement, chance agreement from the two base rates (two raters flagging 94% each agree ~89% by coincidence); for TPR, the flag rate (a monitor flagging everything has TPR 1.0); for a union or ensemble gain, the same component used twice. Where a null is cheap to simulate, prefer a permutation that preserves marginals and destroys correspondence over the closed-form value — it is the same claim, demonstrated. State the **ceiling** too where one exists: the same instrument measured twice bounds how much any difference between instruments can mean. Report chance-corrected effects (kappa, lift over shuffled) alongside raw ones, and when a raw number moves a lot, decompose the move into base-rate and signal parts. A significant but negligible margin is described as "small and real", never as "at chance" and never as the raw figure alone.

**Causal claims match the evidence.** Default register: associated with, consistent with, suggests, is higher in the X condition, we observe. Reserve causal verbs ("causes", "drives", "proves", "demonstrates") for tested mechanism or RCT-style designs; never "smoking gun" / "definitively shows". When the evidence is strong, state the claim plainly — the result speaks.
