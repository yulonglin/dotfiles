# Source prompts, verbatim

Yulong's own meta-prompts, kept unedited. The taste files distil these; these are the originals to diff against when the distillation drifts, and they are usable as prompts on their own.

Do not edit these to match a taste file. If they disagree, the source wins and the taste file is wrong.

| File | Used as |
|---|---|
| `research-brainstorming.md` | a prompt for generating and filtering research ideas |
| `monitoring-analysis.md` | a prompt for analysing model-monitoring results |
| `presentation-checklist.md` | a review pass over slides, reports and dashboards |

Each carries its own `#prompt/meta` tag from Bear, where they are maintained.
