Rigour Checks Review

Every rigour, reproducibility and research-integrity check the harness asks of an experiment, with one row per distinct check and every place it is stated. Each row is rated for what it costs an experiment iteration and what it catches, with a suggested disposition. Set a decision on each row; Claude reads the decisions back and edits the rules, checklists, skills and agents to match.

Most checks are text, and five cost the most

  • Only 3 of 75 checks run as code. Four guards are built and tested but not wired into the live settings (existing code, synthetic data, hyperparameter provenance, number provenance). nudge_experiment_jobs is wired but switched off. Wiring them is cheap and turns text into enforcement.
  • Five checks cost iteration speed most, all human waits: D13 research-engineer's blocking spec gate (lean drop), D14 two plan-mode gates per experiment (lean soften), D06 an hour attacking each detector (lean: only before quoting a number), D16 the overnight pre-launch review (lean: go on a stated default after a timeout), and P06 the spend gate at $100 (lean keep). Runner-up: U08, two seeds for a quoted result.
  • Five pairs of files contradict each other, listed below. Each needs one answer, not a vote per row.
  • Suggested dispositions: . The ratings and leans come from a Claude Opus 5.5 sweep and are a starting point, not a verdict.

Five contradictions need one answer each

  • Interval formula. ci-standards.md:17-20 uses mean ± 1.96 SE for every score; results-artifact:14 says Wilson for proportions, never the normal approximation. The same pair disagrees on whether non-overlapping intervals can stand in for a test. data-analyst, research-skeptic and experiment-designer all point at ci-standards.
  • Point estimate without an interval. data-analyst:274 says never; sandbagging.md:54 says give the point estimate alone when the only interval is degenerate.
  • Seed count. The checklists set at least 2 seeds for any quoted result (experiments.md:66); research-engineer only warns and suggests 5; inspect-ai-evals makes extra seeds a second phase once a signal shows. Reconcilable as explore versus quote, but no file says so.
  • Human gates against "commit and run". CLAUDE.md says proceed on partial answers; research-engineer:99-167 stops and waits for the user, and verification-planning plus require_plan_approval.sh add two gates per experiment in this repo.
  • Multiple comparisons. data-analyst and experiment-designer require Bonferroni or FDR correction; research-core:11 asks only that the number of slices and comparisons be stated.
  • Softer tensions: sandbagging.md:31 reads the behaviour-free baseline as the detector's bar; the transcript checklist triages by keyword while llm-judge forbids keywords for meaning (fine as triage, unlabelled); spec-interview-research points at a pilot gate that moved to experiments.md; three checklists still say "arm".
